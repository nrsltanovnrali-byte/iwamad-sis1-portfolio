## About the Project

This is my personal portfolio website.
I built it using HTML, CSS and JavaScript.
It includes information about me, my projects and a contact form.

## Design Decisions

1. I used CSS Grid to show three project cards on desktop and one on mobile.
2. I chose blue and neutral colors to keep the design simple and readable.
3. After testing at 375px, I reduced the navigation spacing to make it more comfortable on phones.

## Features

- Responsive layout
- Dark and light mode
- Contact form validation
- Navigation between sections
